## 📌 About the Project

This project explains **Rainbow Tables**, a technique used in password security research to identify passwords from certain precomputed hash chains.

It explores how password hashing works, how rainbow tables operate, why weak password storage is vulnerable, and how developers can protect authentication systems.

The project is designed for beginners, cybersecurity students, and anyone interested in ethical hacking and password security.

## 🎯 Project Objectives

- Understand password hashing.
- Learn how rainbow tables work.
- Explore hash chains and reduction functions.
- Understand the differences between rainbow tables and brute-force attacks.
- Demonstrate password security concepts using Python.
- Learn how salts and secure password-hashing algorithms protect passwords.

## 🧪 Practical Demonstration

This repository includes a beginner-friendly Python demonstration of simplified hash chains.

The lab uses sample password candidates and SHA-256 to explain the basic concepts behind hash-chain generation.

**Note:** This is an educational demonstration, not a complete production rainbow-table implementation.

## 🛡️ Security and Prevention

Important password security practices covered in this project:

- Use unique random salts.
- Store passwords using Argon2id, bcrypt, or scrypt.
- Avoid storing plain-text passwords.
- Use strong and unique passwords.
- Enable multi-factor authentication.
- Protect password databases.
